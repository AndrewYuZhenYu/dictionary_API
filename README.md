# 多彩词汇解析 v10

词汇解析应用。页面在 `dictionary_v10.html`，使用自己的 DeepSeek API Key 查询英文单词、短语及中文表达。第九版保留在 `dictionary_v9.html`。

## v10 定档更新（2026-10-17）

第十版已定档。相对第九版，本次更新集中在阅读界面、单词解析内容和流式响应：

- **界面与标识**：重做页面布局和动效，解析内容采用带编号及颜色区分的卡片；页头换成叠放的「中 / A」双语词卡图标。放大正文与辅助文字，使用 macOS、Windows 和 Android 均有回退的系统字体，并适配窄屏、深色主题与系统的减少动态效果设置。
- **单词解析**：在音标与中文释义之间加入英文释义；中英文释义按词性分行。在派生词与形近词辨析之间加入「句型与语法搭配」，说明常见句型、语法限制与例句。原有提示词内容保留，新要求追加在后面。
- **响应与稳定性**：保留边生成边显示的流式体验；本地服务可转发 DeepSeek 请求，避开浏览器直连可能遇到的跨域限制。新查询会取消旧请求；截断、断流或超时的结果会标明为未完成，且不会写入缓存。
- **词库与安全**：查询缓存、收藏和复习进度分开保存；清理查询缓存不会清除收藏。模型返回的内容经受控渲染，旧版 HTML 缓存经过标签白名单处理。

英文释义由模型按学习者词典的风格生成，没有直接连接牛津或朗文数据库，也不保证与词典原文一致。

## 运行

推荐使用 Node.js 18 或更新版本，在项目目录运行 `npm start`（或 `node server.js`），然后打开 `http://127.0.0.1:8787/dictionary_v10.html`。本地服务仅监听本机地址，提供页面并把流式 API 请求转发给 DeepSeek；不安装额外依赖，也不保存 API Key。从 `file://` 切换到该地址后，需要重新输入一次 API Key。

如果使用其他静态服务器或直接打开 HTML，页面会由浏览器直连 DeepSeek。浏览器可能因网络或跨域限制报 `Failed to fetch`，因此本地使用建议走上面的服务。

首次使用时展开「连接 DeepSeek」，输入 API Key 并保存。密钥只写入当前标签页的 `sessionStorage`；关闭标签页后通常需要重新输入。第十版首次打开时会把旧版留在 `localStorage` 的密钥迁移到当前会话，并删除旧副本。本地代理仅转发当前请求中的密钥，不持久化。

> 直接双击 HTML 会以 `file://` 打开，无法使用本项目的本地代理。

## 功能

- 英文词汇、短语及中文表达解析。单个英文单词在音标与中文释义之间增加英文释义；英文与中文释义按词性逐行显示。在派生词与形近词辨析之间增加句型与语法搭配，原有解析板块保留。
- Markdown 正文边接收边显示；渲染器只创建受控 DOM 元素，模型返回的 HTML 会作为普通文字显示。旧版 HTML 缓存经过标签白名单清理后显示。
- 支持结果内点击英文词继续查询、右键选词查询、前进后退、历史记录和目录导航。
- 查询缓存、独立收藏、待复习列表。收藏及复习进度在清理缓存时保留。
- 待复习卡片可选「已掌握」或「再练一次」。已掌握后依次延至 1、3、7、14、30 天；再练一次会在 10 分钟后到期。这是轻量提醒机制，不记录答题成绩。
- 导出缓存与收藏词条为文本；收藏词条以 `★` 标识。
- 明暗主题、响应式布局、系统字体回退，以及“减少动态效果”支持。

## 查询与缓存

请求使用 DeepSeek Chat Completions 的 `deepseek-flash` 模型、关闭思考模式并使用 SSE 流。正文按行增量插入页面，不会在每个片段到达时重建整篇内容；正常结束后才写入缓存。连接等待上限为 12 秒，流期间 25 秒没有新数据会中断。长度截断、断流或超时会保留已生成的可读内容，并标明它未写入缓存。发起新查询或切换导航会取消旧请求，旧响应不会覆盖新结果。

查询缓存上限为 200 条，历史记录上限为 50 条。缓存包含模型与提示词格式版本；单个英文单词的旧解析会重新查询以生成英文释义和句型模块，短语与中文表达的现有缓存继续使用。旧版 `word_cache_v5_*` HTML 缓存及先前第十版的结构化缓存可用于短语和中文表达。收藏列表与缓存分开存放：删除单条缓存、清空词库缓存或使用页面清理按钮，都不会删除收藏及复习进度。若要删除收藏，可在结果页或词库卡片取消收藏。

页面不会把模型输出的 HTML 当作可执行页面内容。英文释义由模型按牛津或朗文学习者词典的风格概括，不是经词典核对的原文。模型生成的释义、例句或翻译仍需用户自行判断准确性。

## 本地数据

| 存储位置 / Key | 内容 |
|---|---|
| `sessionStorage: deepseek_api_key_v5` | 当前标签页的 API Key |
| `localStorage: word_cache_v10_md_*` | 流式 Markdown 解析缓存 |
| `localStorage: word_cache_v10_*` | 先前第十版结构化解析缓存，兼容读取 |
| `localStorage: word_cache_v5_*` | 可读取的旧版 HTML 缓存 |
| `localStorage: word_favorites_v10` | 收藏和复习进度 |
| `localStorage: word_history_v5` | 最近查询 |
| `localStorage: nav_stack_v8`、`nav_index_v8` | 前进后退导航 |
| `localStorage: color_theme_v5` | 主题偏好 |
| `localStorage: toc_side_v9` | 桌面目录位置 |

清除浏览器站点数据会删除这些缓存、收藏和偏好。页面无外部脚本或字体依赖。通过本地服务打开时由 `server.js` 转发联网请求；其他打开方式由浏览器直连 DeepSeek API。

## 开发说明

页面、样式和前端逻辑在 `dictionary_v10.html`；可选本地代理在 `server.js`。原有内容模板由 `buildSystemPrompt()` 生成，单个英文单词的新要求由 `buildPromptWithSingleWordAdditions()` 追加。`createStreamingRenderer()` 逐行追加安全 DOM，`renderMarkdownResult()` 仅在完成时统一排版；`renderStructuredResult()` 用于读取先前第十版缓存。`analyzeWord()` 处理请求取消、SSE、超时与完成状态。`getCachedResult()` 读取新版缓存并兼容旧版缓存。`favoriteEntries` 维护独立收藏及复习时间。

运行 `npm test` 检查页面解析、缓存及流式请求；运行 `npm run test:server` 检查本地代理。

用户需要在浏览器输入自己的密钥。本地代理只在本机使用；若部署为公开服务并希望统一管理密钥，需要另行设计服务端认证和访问控制。
